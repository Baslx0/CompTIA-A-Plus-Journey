# Objective 1.1 — Mobile Device Hardware

**Official objective:** Given a scenario, monitor mobile device hardware and use appropriate replacement techniques.

## Resources

- Professor Messer

## Key concepts

Laptop hardware is usually less modular than desktop hardware. Components are packed into a smaller space, and some parts may be soldered or integrated into the device, which can make replacement more difficult.

The main serviceable components I focused on include:

- battery;
- RAM;
- HDD / SSD;
- wireless card;
- keyboard;
- camera and microphone;
- physical privacy/security components.

### Wi-Fi antenna placement

Laptop Wi-Fi antennas are commonly routed through the display assembly. If wireless performance becomes poor after screen or display work, the antenna connectors or routing are worth checking.

## Key takeaway

Mobile-device repair often involves the same basic components found in larger computers, but tighter integration and limited space make serviceability more important.
