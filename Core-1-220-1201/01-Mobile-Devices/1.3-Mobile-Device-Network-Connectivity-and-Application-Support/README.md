## Key concepts

Mobile devices can connect through cellular networks, Wi-Fi, hotspots, Bluetooth, SIM/eSIM, and location services such as GPS.

### Bluetooth pairing

A typical pairing flow is:

**Enable Bluetooth → Enable pairing → Find the device → Enter/confirm PIN if required → Test connectivity**

### Mobile Device Management (MDM)

MDM is used by organizations to centrally manage mobile devices.

It can be used for:

- corporate device configuration;
- BYOD policies;
- policy enforcement;
- deployment of corporate applications.

A useful distinction is that **MDM manages devices and their policies**, while a network security appliance such as a UTM focuses on protecting/filtering network traffic.

### Synchronization

Mobile devices may synchronize:

- calendar;
- contacts;
- mail;
- business applications;
- cloud storage.

Data caps matter when synchronization occurs over cellular connections.

## Key takeaway

This objective is mainly about connecting a mobile device correctly and understanding how organizations configure, manage, and synchronize those devices.
