# Objective 3.1 — Display Components and Attributes

**Official objective:** Compare and contrast display components and attributes.

## Display technologies

### LCD panel types

- **IPS (In-Plane Switching)** — known for strong color quality and wide viewing angles.
- **TN (Twisted Nematic)** — traditionally associated with fast response times, but weaker viewing angles and color quality.
- **VA (Vertical Alignment)** — known for strong contrast and generally good color quality.

IPS, TN, and VA are all **LCD panel technologies**.

### OLED

OLED pixels are **self-emissive**, so they do not require a separate backlight. Individual pixels can turn off completely, which enables very deep blacks and high contrast.

### Mini-LED

Mini-LED is still an **LCD-based display technology**. It uses many small LEDs as the backlight and divides them into local-dimming zones for more precise brightness control.

Important distinction:

- **OLED:** controls light at the individual-pixel level.
- **Mini-LED:** controls the backlight in zones.

## Touch screen and digitizer

A **digitizer** detects touch or stylus input and converts that interaction into data the system can process. The display produces output; the digitizer handles the touch-input side.

## Inverter

In older LCD backlight designs, an **inverter** converts DC power to AC power for the backlight.

## Display attributes

### Screen resolution

The pixel dimensions of the displayed image, such as:

- 1920 × 1080
- 2560 × 1440
- 3840 × 2160

### Pixel density

How tightly pixels are packed into the physical display area, commonly measured in **PPI (pixels per inch)**.

Useful relationships:

- Same screen size + higher resolution = higher pixel density.
- Same resolution + smaller screen = higher pixel density.
- Same resolution + larger screen = lower pixel density.

### Refresh rate

How many times the display updates the image per second, measured in **Hz**.

Example: 144 Hz means the display can refresh the image 144 times per second.

### Color gamut

The range of colors a display can reproduce.

## Useful distinction

A screen specification may describe different independent properties:

- **27 inches** = physical screen size
- **2560 × 1440** = resolution
- **144 Hz** = refresh rate
- **PPI** = pixel density
- **Color gamut** = reproducible color range

Do not infer one attribute from another unless the required information is provided.

## Key takeaway

Keep the display attributes separate: resolution is pixel count, pixel density is how tightly those pixels are packed, refresh rate is updates per second, and color gamut is the range of colors the display can reproduce.
