# Objective 2.8 — Networking Tools

**Official objective:** Explain networking tools and their purposes.

## Key tools

- **Crimper** — attaches modular connectors such as RJ45 plugs to network cable.
- **Cable stripper** — removes the outer jacket or insulation without damaging the conductors.
- **Punchdown tool** — seats individual conductors into IDC terminals on patch panels and keystone jacks.
- **Cable tester** — checks cable continuity, wiring, and basic integrity.
- **Toner probe** — traces and identifies a specific cable in a bundle or wall run.
- **Wi-Fi analyzer** — examines wireless signal strength, channel usage, and interference.
- **Loopback plug** — tests whether a network interface can send and receive through its own port.
- **Network tap** — provides a copy of network traffic for monitoring without making the monitoring device the traffic destination.

## Useful distinctions

### Crimper vs punchdown tool

- **Crimper:** cable → modular plug such as RJ45
- **Punchdown tool:** cable conductors → patch panel or keystone jack

### Network tap vs port mirroring

Both are used to observe network traffic.

- **Network tap:** physical hardware placed in the traffic path that copies traffic to a monitoring device.
- **Port mirroring:** a managed-switch feature that copies traffic from one or more ports to a monitoring port.

## Key takeaway

Choose the tool based on the job: prepare cable, terminate it, trace it, test it, analyze wireless conditions, test an interface, or observe traffic.
