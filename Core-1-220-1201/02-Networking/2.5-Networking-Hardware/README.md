## Key concepts

- **Router:** connects different IP networks and forwards traffic between them.
- **Switch:** connects devices inside a LAN.
  - **Managed switch:** supports configuration and features such as VLANs.
  - **Unmanaged switch:** basic plug-and-play switching.
- **Access point:** provides wireless access to a wired network.
- **Patch panel:** passive termination/organization point for network cabling.
- **Firewall:** filters traffic according to security rules.
- **PoE:** carries electrical power over Ethernet cabling to devices such as access points or IP phones.
- **Cable modem:** provides Internet connectivity over a cable network.
- **DSL modem:** provides connectivity over telephone-line infrastructure.
- **ONT:** terminates a fiber connection at the customer premises.
- **NIC:** connects a device to a network and has a physical MAC address.

## Key takeaway

The important distinction is the role each device plays: forwarding between networks, connecting devices inside a network, providing wireless access, securing traffic, terminating ISP service, or providing the endpoint's network interface.
