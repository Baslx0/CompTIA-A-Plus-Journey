## Common server roles

- **DNS server:** resolves names to network addresses.
- **DHCP server:** automatically provides IP configuration.
- **File server:** central file storage and sharing.
- **Print server:** manages shared printing.
- **Mail server:** handles email services.
- **Syslog server:** centralizes logs.
- **Web server:** hosts web content/services.
- **Database server:** stores and serves structured data.
- **NTP server:** provides time synchronization.

## AAA

**Authentication, Authorization, and Accounting**

- **Authentication:** Who are you?
- **Authorization:** What are you allowed to access or do?
- **Accounting:** What activity or resource usage should be recorded?

## Internet appliances

A useful distinction from my review:

- **Proxy:** acts as an intermediary for client requests and can filter/control access.
- **Firewall:** permits or blocks network traffic based on security rules.

Other appliances in this objective include spam gateways, UTM devices, and load balancers.
