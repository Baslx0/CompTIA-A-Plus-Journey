## Internet connection types

- **Fiber:** very high bandwidth and low latency using optical fiber.
- **Cable:** Internet service delivered over cable/coax infrastructure.
- **DSL:** Internet service delivered over telephone-line copper.
- **Satellite:** useful where terrestrial service is unavailable, but latency is typically higher.
- **Cellular:** Internet access over a mobile network.
- **WISP:** wireless Internet service delivered to customers through wireless links.

## Network types

- **LAN:** local network covering a limited area such as a home, office, or building.
- **WAN:** connects networks across large geographic areas.
- **PAN:** short-range network around an individual, such as Bluetooth devices.
- **MAN:** connects networks across a metropolitan/city-scale area.
- **SAN:** dedicated network used to provide systems with access to centralized storage.
- **WLAN:** a local area network using wireless connectivity.

### SAN vs. NAS

A distinction that is easy to mix up:

- **SAN:** a storage network.
- **NAS:** a storage device/service attached to a network.

## Key takeaway

For network types, think about either **geographic scope** or **purpose**. For Internet connections, compare the delivery medium, performance, availability, and typical use case.
