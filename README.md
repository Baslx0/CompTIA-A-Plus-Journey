# CompTIA A+ Learning Journey

This repository documents my journey toward the **CompTIA A+ certification**, starting with **Core 1 (220-1201)** and continuing with **Core 2 (220-1202)**.

My goal is not to build another giant A+ study guide. I want to share the way I am learning, the resources I use, the notes that help concepts make sense, and the progress I make along the way.

## Study approach

My study loop is simple:

**Watch → Ask → Test → Find gaps → Practice → Continue**

- **Professor Messer** is my primary course.
- The **official CompTIA exam objectives** are my coverage roadmap.
- I use **ExamCompass** for independent knowledge checks.
- I use **ChatGPT** when I need a concept explained differently or want troubleshooting / PBQ-style practice.
- I document useful notes and distinctions without trying to rewrite the entire course.

More detail: [STUDY-METHOD.md](./STUDY-METHOD.md)
